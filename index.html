pdfReader 英語のPDFを耳で読む

最近のPDF

    まだありません。開いたPDFはこの端末のブラウザ内に保存され、次回は続きから再生できます。

    使い方のヒント
    • Safariの共有ボタン →「ホーム画面に追加」で、アプリのように全画面で使えます。
    • 声は iPhone の「設定 › アクセシビリティ › 読み上げコンテンツ › 声 › 英語」で追加できます。高音質版をダウンロードすると、声の一覧に出てくる場合があります。
    • 画面をロックすると読み上げが止まることがあります。読み上げ中は画面を消さない設定がおすすめです(設定はメニュー内)。
    • テキスト表示で文をタップすると、そこから読み上げます。長押しで単語を選べば、iPhone標準の「調べる」「翻訳」が使えます。
    • 上の「訳」ボタンで、読んでいる文の日本語訳を表示できます。訳はGoogle翻訳で作るので、表示する文とその先の数文だけがGoogleに送られます。

    今月の使用量

    0 / 1,000,000 文字(無料枠)

    上限が無料枠を超えています。超えた分は100万文字あたり約30ドルかかります。

    キーはブラウザに保存しません。アプリを閉じると消えるので、開くたびに入れてください。iPhoneのパスワード自動入力に保存しておくと、Face IDですぐ入れられます。

    文字/月
    • 声は Google の Chirp 3 HD です。毎月100万文字まで無料で、空白も1文字に数えます。
    • 一度読んだ文の音声は端末に保存して使い回すので、巻き戻しや読み直しでは使用量は増えません。速度を変えても増えません。
    • 使用量はこの端末で数えた値です。ほかの端末でも同じキーを使うなら、Google Cloud の「お支払い」画面でも確認してください。
    • 画面をロックしても読み上げが続きやすく、ロック画面から一時停止や文の移動もできます。
    APIキーの作り方
    1. Google Cloud Console にログインし、プロジェクトを作ります。
    2. 「お支払い」で請求先アカウントを作ります(クレジットカードの登録が必要。無料枠の中なら請求はありません)。
    3. 「APIとサービス › ライブラリ」で「Cloud Text-to-Speech API」を有効にします。
    4. 「APIとサービス › 認証情報」で「認証情報を作成 › APIキー」を選びます。
    5. 作ったキーの設定で、「APIの制限」を Cloud Text-to-Speech API だけに、「ウェブサイトの制限」を https://hi6to.github.io/* にします。
    6. 念のため「お支払い › 予算とアラート」で、予算100円などのアラートを作っておくと、課金が発生したときにメールで分かります。
    7. キーをこの画面に貼り付けて「保存」を押します。

        操作のヒント

        • 前の文:文の途中なら文頭へ、文頭なら1つ前の文へ戻ります。
        • 10秒戻る/進む:文字数から計算したおおよその時間です。
        • 訳:画面上の「訳」ボタンで、読んでいる文の日本語訳を表示します。表示する文とその先の数文だけがGoogle翻訳に送られます。
        • キーボード:スペースで再生/停止、← → で文単位、Shift+← → で10秒、T で訳の表示。
