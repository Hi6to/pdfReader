# pdfReader

英語のPDFを読み上げる、iPhone向けのブラウザアプリ。個人利用のためのもので、Safari / Chrome で動きます。
ビルドは不要で、`index.html` `style.css` `app.js` の3ファイルだけで動く静的サイトです。

## できること

- **読み上げ**:ブラウザ標準の音声合成(Web Speech API)を使います。初期設定では女性の英語音声(iPhoneなら Samantha など)を優先して選びます。声が単語の位置を通知してくれる場合(iPhoneのSafariなど)は段落をまとめて1回で読むので、文と文の間が自然につながります
- **iPhoneの設定の声(高音質向け)**:Safariは、ダウンロードした高音質の声(Ava プレミアムなど)を声の一覧に出しません。「設定アプリで選んだ声」を選ぶと、声を指定せず言語だけで読ませるので、設定アプリの「読み上げコンテンツ › 声」で選んだ高音質の声で読める場合があります(iOSのバージョンによります)
- **クラウドの声(任意)**:Google Cloud の Chirp 3 HD に切り替えると、より人に近い声で読みます。端末の声といつでも切り替えられます(下の「クラウドの声」参照)
- **位置の調整**:
  - テキスト表示で文をタップ → その文から読む
  - PDF表示でページ上の文をタップ → その文から読む
  - シークバー、ページ番号での移動、本文検索
- **巻き戻し・早送り**:前の文 / 次の文、約10秒戻る / 進む(文字数から計算した目安)
- **速度**:0.5〜2.0倍。再生中に変えると、いま読んでいる単語から読み直します
- **ハイライト**:読んでいる文と単語に色が付き、自動でスクロールします
- **日本語訳**:上の「訳」ボタンで、読んでいる文の日本語訳をプレイヤーの上に表示します(Google翻訳を使用)。ページごとにまとめて1回で取り、取った訳はPDFごとに端末(IndexedDB)へ保存するので、同じPDFは次から通信なしで表示できます。Google翻訳に一時的に止められたときは、原因と再開の時刻を表示して、しばらく自動では取りに行きません
- **続きから再生**:開いたPDFはブラウザ内(IndexedDB)に保存され、本棚から開くと前回の位置から再開できます
- **リピート**:「1文」「ページ」を切り替えられます。「ページ」では、いま読んでいるページの最後まで読んだら同じページの最初に戻ります。文と文の間の無音(シャドーイング用)も入れられます
- **ネイティブらしい読み方**:声に出して読むときの言い方に直してから読みます。画面の文はそのままです
  - 略語:「e.g.」→ for example、「i.e.」→ that is、「Fig. 3」→ Figure 3、「Eq. (2)」→ Equation (2)、「Sec.」→ Section、「pp. 12–15」→ pages 12 to 15、「vs.」→ versus など
  - 数の範囲「10–20」→ 10 to 20、「~10」→ about 10、指数「10⁵」→ 10 to the power of 5、「and/or」→ and or、「w/o」→ without、「Chapter IV」→ Chapter 4。全部大文字の見出しはふつうの書き方にして読みます
  - 単語の右上の脚注番号(word¹)は読みません
  - 段落の変わり目と見出しの前後に、ナレーターのような間を入れます
  - 論文の著者と年の引用「(Smith et al., 2020; Lee, 2019)」は読み飛ばします(引用番号の設定と同じスイッチ)
- **その他**:しおり、スリープタイマー、声の高さ、文字サイズ・書体・ダークモード、読み上げ中は画面を消さない(Wake Lock)
- **PDFの癖への対策**:ヘッダー・フッター・ページ番号の除去、行末ハイフンで分かれた単語の連結、引用番号 `[12]` やURLの読み飛ばし、長い文の分割
- **数式を読まない**:数式だけの行(式番号や添字の行も含む)と、文の中の数式(`x ∈ R^d` など)を読み飛ばします。読み飛ばした場所には「数式」の印が出て、タップするとPDF表示でそのページを開きます

## iPhoneで使う

静的ファイルをHTTPSで配信できる場所に置けば使えます(GitHub Pages など)。
Safariで開いて、共有ボタン →「ホーム画面に追加」すると全画面のアプリのように使えます。

声を増やしたいときは、iPhoneの「設定 › アクセシビリティ › 読み上げコンテンツ › 声 › 英語」から追加します。

## クラウドの声

「声」ボタン →「クラウドの声」で、Google Cloud Text-to-Speech の Chirp 3 HD(女性の声)を使えます。

- **料金**:毎月100万文字まで無料。超えた分は100万文字あたり約30ドル。空白や改行も1文字に数えます
- **使用量の表示**:今月使った文字数と無料枠の残りを、声の画面に表示します。月の区切りはGoogleの請求月(米国太平洋時間)に合わせています
- **上限**:初期値は90万文字。上限に収まらなくなったら、自動で端末の声に切り替えます。上限は無料枠(100万文字)より上には設定できません
- **段落単位の音声**:1文ずつではなく段落(長い段落は約900文字ごと)をまとめて1つの音声にするので、ナレーターのように文と文が自然につながります。音声の中の無音の位置から文の区切りを求めて、文ごとのハイライト・移動・リピートを行います
- **使用量を増やさない工夫**:一度作った音声は端末(IndexedDB)に保存して使い回します。巻き戻し・読み直し・速度変更・リピートでは使用量は増えません。途中の文から読み始めた場合も、その段落の音声をまとめて作ります
- **注意**:使用量はその端末で数えた値です。複数の端末で同じキーを使う場合は、Google Cloud の「お支払い」画面でも確認してください
- **おまけ**:音声ファイルとして再生するので、画面をロックしても読み上げが続きやすく、ロック画面から一時停止や文の移動ができます

### APIキーの作り方

1. [Google Cloud Console](https://console.cloud.google.com/) でプロジェクトを作る
2. 「お支払い」で請求先アカウントを作る(クレジットカードの登録が必要。無料枠の中なら請求はない)
3. 「APIとサービス › ライブラリ」で **Cloud Text-to-Speech API** を有効にする
4. 「APIとサービス › 認証情報」→「認証情報を作成 › APIキー」
5. キーの設定で「APIの制限」を Cloud Text-to-Speech API のみに、「ウェブサイトの制限」を `https://hi6to.github.io/*` にする
6. 念のため「お支払い › 予算とアラート」で少額の予算アラートを作っておく(課金が発生したらメールで分かる)
7. アプリの「声 › クラウドの声」にキーを貼り付けて「使う」

キーはブラウザのどこにも保存しません(メモリに持つだけで、アプリを閉じると消えます)。開くたびに入れ直す必要がありますが、iPhoneのパスワード自動入力(iCloudキーチェーン)に保存しておけば、Face IDですぐ入れられます。キーが送られる先は Google の Text-to-Speech API だけです。

## 手元で動かす

任意の静的サーバーで配信します。例:

```bash
npx serve .
```

## データの扱い

PDFは端末のブラウザ内だけで処理・保存され、どこにもアップロードされません。
例外は次の2つです。

- 日本語訳を表示しているときは、読んでいるページ(と、ページの終わりで先読みする次のページ)の文がGoogle翻訳に送られます
- クラウドの声を使っているときは、読む文(と先読みする3文)が Google Cloud Text-to-Speech に送られます

## 制限

- スキャンした画像だけのPDF(文字データがないもの)は読み上げできません
- 端末の声では、iPhoneで画面をロックしたりアプリを切り替えたりすると、読み上げが止まることがあります(ブラウザの音声合成の制約)。戻ると続きから再開します
- クラウドの声では、単語ごとのハイライトはなく、文ごとのハイライトになります。声の高さの調整も使えません
- 「10秒戻る/進む」と残り時間は文字数からの推定です
- 声の自然さは端末の音声合成しだいです。iPhoneでは、設定アプリでダウンロードした高音質の声がブラウザから使えないことがあります
- 日本語訳はGoogle翻訳の非公式エンドポイントを使っています。1つのIPアドレスから短い時間にたくさん使うと一時的に止められます(数分〜1日ほど)。iCloudプライベートリレーを使っていると、ほかの人とIPアドレスを共有するので止められやすくなります
- PDFの描画とテキスト抽出には [PDF.js](https://mozilla.github.io/pdf.js/) 3.11.174 を使っています。プログラムは `vendor/` にリポジトリ内のコピーを置いていて、外部のCDNからスクリプトは読み込みません(文字の対応表とフォントのデータだけ jsDelivr から取ります)
