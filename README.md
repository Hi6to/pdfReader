# pdfReader

英語のPDFを読み上げる、iPhone向けのブラウザアプリ。個人利用のためのもので、Safari / Chrome で動きます。
ビルドは不要で、`index.html` `style.css` `app.js` の3ファイルだけで動く静的サイトです。

## できること

- **読み上げ**:ブラウザ標準の音声合成(Web Speech API)を使います。初期設定では女性の英語音声(iPhoneなら Samantha など)を優先して選びます
- **位置の調整**:
  - テキスト表示で文をタップ → その文から読む
  - PDF表示でページ上の文をタップ → その文から読む
  - シークバー、ページ番号での移動、本文検索
- **巻き戻し・早送り**:前の文 / 次の文、約10秒戻る / 進む(文字数から計算した目安)
- **速度**:0.5〜2.0倍。再生中に変えると、いま読んでいる単語から読み直します
- **ハイライト**:読んでいる文と単語に色が付き、自動でスクロールします
- **日本語訳**:上の「訳」ボタンで、読んでいる文の日本語訳をプレイヤーの上に表示します(Google翻訳を使用。先の数文もまとめて取得します)
- **続きから再生**:開いたPDFはブラウザ内(IndexedDB)に保存され、本棚から開くと前回の位置から再開できます
- **学習向け**:1文リピート、文と文の間の無音(シャドーイング用)
- **その他**:しおり、スリープタイマー、声の高さ、文字サイズ・書体・ダークモード、読み上げ中は画面を消さない(Wake Lock)
- **PDFの癖への対策**:ヘッダー・フッター・ページ番号の除去、行末ハイフンで分かれた単語の連結、引用番号 `[12]` やURLの読み飛ばし、長い文の分割

## iPhoneで使う

静的ファイルをHTTPSで配信できる場所に置けば使えます(GitHub Pages など)。
Safariで開いて、共有ボタン →「ホーム画面に追加」すると全画面のアプリのように使えます。

声を増やしたいときは、iPhoneの「設定 › アクセシビリティ › 読み上げコンテンツ › 声 › 英語」から追加します。

## 手元で動かす

任意の静的サーバーで配信します。例:

```bash
npx serve .
```

## データの扱い

PDFは端末のブラウザ内だけで処理・保存され、どこにもアップロードされません。
例外は日本語訳で、訳を表示しているときに限り、訳す文(と先読みする数文)がGoogle翻訳に送られます。

## 制限

- スキャンした画像だけのPDF(文字データがないもの)は読み上げできません
- iPhoneで画面をロックしたりアプリを切り替えたりすると、読み上げが止まることがあります(ブラウザの音声合成の制約)。戻ると続きから再開します
- 「10秒戻る/進む」と残り時間は文字数からの推定です
- 日本語訳はGoogle翻訳の非公式エンドポイントを使っているため、使いすぎると一時的に取得できなくなることがあります
- PDFの描画とテキスト抽出には [PDF.js](https://mozilla.github.io/pdf.js/) 3.11.174(jsDelivr経由)を使っています
